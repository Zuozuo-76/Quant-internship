# 多股票分钟线 LSTM Walk-forward 拓展

- 股票数：6（000012, 000014, 000019, 000020, 000027, 000030）
- 日期范围：20250401 至 20251028，共 140 个交易日
- 输入窗口：过去 20 分钟
- 特征：log_return, range, log_volume, buy_sell_imbalance, time_position
- 模型：PyTorch ``torch.nn.LSTM``（hidden=16）+ 线性二分类头
- 验证方式：3 个 expanding-window walk-forward 折
- 每折：至少 60 个训练日、20 个验证日、20 个不重叠测试日
- 标准化和模型训练均在每折内重新估计，不使用测试期信息

## 合并样本外测试

- 样本数：83880
- 上涨占比：31.09%
- 多数类基线准确率：68.91%
- LSTM 准确率：68.98%
- 平衡准确率：52.28%
- Precision：50.77%
- Recall：8.10%
- F1：13.97%
- ROC AUC：0.6465
- PR AUC：0.4276
- 混淆矩阵：TN=55749, FP=2049, FN=23969, TP=2113

## 简单模型基线

- 逻辑回归准确率：68.93%
- 逻辑回归平衡准确率：51.23%
- 逻辑回归 ROC AUC：0.6086
- 逻辑回归 PR AUC：0.3993
- 逻辑回归 F1：8.10%

这是多股票、长时间和严格滚动样本外结果。是否可交易仍需结合阈值、换手、滑点和延迟进行策略级验证。
